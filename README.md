# 🌿 Leaf Detection Project

A web-based leaf detection project built using **Python (FastAPI)** for the backend and **HTML, CSS, and JavaScript** for the frontend.

## ✨ Features
- Upload or input leaf data for detection
- Fast and lightweight backend powered by FastAPI
- Clean, responsive web interface

## 🛠️ Tech Stack
- **Backend:** Python, FastAPI
- **Frontend:** HTML, CSS, JavaScript
